## 免费试读：让 AI 说人话的 4 个模板

**模板 1：禁止废话**
```text
回答我这个问题时，遵守 3 条规则：
①直接给结论，不要铺垫，不要"首先/其次/总而言之"
②每句话都要有信息量，删除任何正确的废话
③如果某句话删掉不影响理解，说明它就该删
问题：{你的问题}
```

**模板 2：强制给具体例子**
```text
回答时不要只讲道理，每个观点必须配一个真实可操作的例子。
例子格式：场景 → 做法 → 结果。
如果给不出具体例子，就明确说"这个点我给不出实例"。
问题：{你的问题}
```

**模板 3：逼它给观点**
```text
不要给我"一方面…另一方面…"的两边话。
请站在「你的立场」给出明确判断和理由，
最后用一句话总结你的核心观点。如果信息不足，先告诉我缺什么信息。
问题：{你的问题}
```

**模板 4：像人一样说话**
```text
请用「真人聊天的语气」回答：
①允许口语化 ②禁止"综上所述""总而言之" ③句子 20 字以内多用短句 ④带一点个人态度
问题：{你的问题}
```
